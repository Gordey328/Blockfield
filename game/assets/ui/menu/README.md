# Baked game-menu previews

These PNGs are actual Compatibility-renderer captures of Blockfield's existing
voxel worlds and original imported OpenSpades weapon meshes. They add no runtime
3D preview scene and no new third-party content. Menu map images are 640×360;
transparent weapon images are 512×192.

`tools/render_menu_previews.gd` reproduces the captures after importing `game/`.
Run Godot with a GPU context, `--path game --script <absolute script path>`.
The output defaults to `game/assets/ui/menu/`; optional `-- --only=mirage` or
`-- --only=rifle,smg,shotgun` regenerates particular images. Import the project
again after generating PNGs so the export includes their texture imports.

`provenance.json` records the exact engine version, source paths and SHA256,
camera framing and image hashes. Expected generation time is roughly 30–120
seconds on a desktop; voxel decoding and chunk meshing dominate that time.

- Crossroads is generated by `game/ai/tdm_arena.gd`.
- The lab is generated by `game/world/voxel_data.gd`.
- Title comes from OpenSpades v0.1.3, commit
  `dcf449c845d509bbde9d79239b32d201c1389961`, using the previously imported
  `game/assets/openspades/maps/Title.vxl`.
- Rifle, SMG and Shotgun use the complete original imported
  `game/assets/openspades/models/Weapons/<weapon>/Weapon.glb` meshes.
  Original-resource provenance and licenses remain under
  `game/assets/openspades/manifest.json` and `game/assets/openspades/licenses/`.
- Mirage uses the already approved bundled `game/assets/maps/csgo_mirage.bfmap`.
  Its supplied-source provenance and licensing limitations remain in
  `game/assets/maps/README.md`. A screenshot does not relicense the source map.
- Dust2 uses the user-approved bundled `game/assets/maps/dust2.bfmap`; its
  Teardown provenance and source restrictions remain in the same map notice.

The bake temporarily disables chunk distance culling for inspection cameras;
the distributed gameplay rendering and simulation are unchanged.
