# Voxel world

The offline Godot world lives in `game/world/`. `VoxelWorld` is the authoritative voxel state for iteration 1. Iteration 2 should feed confirmed server changes through the same boundary. The data model has no node per cube.

## Coordinates and colors

Godot coordinates are `(x east, y up, z south)`, with one unit per block. Blocks occupy `[cell, cell + (1,1,1)]`. The lab is 96 × 32 × 96, with ground layers y=0..3 and walkable top y=4. `get_spawn_position()` returns the current safe map spawn. Always use it rather than a hard-coded height.

`get_block(Vector3i)` returns 0 for air or out-of-bounds. Solid values are `0x01RRGGBB`, so opaque black remains solid. Use `VoxelWorld.pack_color(Color)` and `block_color(int)` at interface boundaries. This differs from OpenSpades' internal `0xHHBBGGRR` which combines color and per-block damage.

Surviving damaged blocks use a separate World mask. Chunk RGB is exactly
`(RGB & 0xfefefe) >> 1`; the damage remains until an actual edit or explicit reset.
Only the mesh containing
the changed color is dirtied; AO, geometry, collider, minimap, VXL and map journal
are unaffected. Controller/confirmed network events mark damage; there is no
automatic health/color expiry. Same-RGB writes are no-ops. Actual edits/reset
clear the mask; joining maps carry the current mask separately from canonical
terrain. See [ADR0010](decisions/0010-persistent-block-damage.md).

Original VXL `(x, y, z)` maps to Godot `(x, 63-z, y)`. The original 512 × 512 × 64 map fits in a 64 MiB `PackedInt32Array`; the vertical column is contiguous. `VXLReader.decode` checks spans, upper/lower colors, hidden solid interiors, truncated inputs and z=62→63 floor duplication. VXL does not store colors inside solid spans; newly exposed interior uses a fixed earth color rather than native randomized interior colors.

## Public boundary

- `generate_lab()` resets the local test arena.
- `get_block(cell)`, `set_block(cell, color)` query or change one cell. Layer y=0 cannot be changed through gameplay.
- `remove_blocks(cells, protect_lower_layer=false)` performs a batch removal and one connectivity pass. Set `protect_lower_layer=true` for grenade/three-block spade actions, matching OpenSpades' protected two bottom layers.
- `cast_voxel(origin, direction, max_dist)` is grid DDA independent of delayed collision rebuilding. It returns `{hit, cell, normal, position}`; `cell + normal` is the placement cell when normal is nonzero.
- `explode(position, radius=1.6)` removes the native axis-aligned 3³ neighborhood and collapses unsupported structures. Radius belongs to player damage/visuals and does not change terrain damage. `explode_sphere(position, radius)` is a separate experimental lab utility.
- `load_vxl(path)` and `load_vxl_bytes(bytes, title)` return a Godot `Error`. A failed decode preserves the current world.
- `await load_vxl_bytes_incremental(bytes,title)` privately decodes bounded column batches, then adopts validated data with deferred visuals. `await encode_vxl_incremental()` encodes one frozen version with virtual small-map padding. `cancel_vxl_jobs()` releases unfinished staging/snapshot buffers; `get_vxl_job_stats()` reports progress/setup/retained logical bytes. New local operations, reset/map replacement and tree exit cancel old jobs. Defaults1024 columns/soft2ms per batch exclude initial allocation, copy-on-write and final adoption/export work. Main selects4096/8ms for operations begun with the menu open,1024/2ms during play. It uses these awaited APIs for original/upload/reset/save; synchronous authority/test APIs stay available. See [ADR0013](decisions/0013-audio-vxl-memory.md) and [evidence](optimization-audio-vxl-memory.md).
- `encode_vxl()` returns native VXL bytes for browser download. `save_vxl(path)` saves those bytes and returns an `Error`; invalid geometry/dimensions return `ERR_INVALID_DATA` before writing. A native map keeps its dimensions; smaller labs are padded to 512 × 64 × 512 at the original x/z origin and y-up heights, with two safe earth layers outside the lab and air above. Areas beyond native dimensions are rejected.
- `set_view_position(player_position)` must be called as the player moves on VXL maps. It streams render meshes and colliders within `render_radius` horizontal chunks; the lab remains fully loaded.
- `set_draw_distance(meters)->float` rounds upward to 16 m chunk steps and clamps to 16..160 m. `get_draw_distance()` returns the actual value. It updates native-map streaming, mesh visibility ranges and water fog; default is 64 m. Increasing distance can synchronously queue many chunks; normal frame processing then amortizes them.
- `set_lighting_enabled(bool)` and `set_ambient_occlusion_enabled(bool)` update one shared shader without rebuilding meshes/collision. Both default to true. Lighting-off uses emissive palette colors, retaining optional AO.
- `set_ambient_occlusion_atlas_enabled(bool)` selects native per-pixel atlas sampling (default true) or the explicit interpolated-corner quality/diagnostic fallback. The existing AO switch disables either mode.
- `set_irradiance_enabled(bool)` controls real source palette single-bounce light, independently of environment ambient light; it defaults off pending browser performance checks. `set_irradiance_light(Color, energy=1)` sets its fixed-source-Sun brightness. `get_irradiance_at(position, normal)->Color` returns the completed coarse-cache contribution; `get_irradiance_stats()` exposes warming progress, memory, work caps and measured update time. The Sun direction is source `(0,+1,+1 Z-down)` / Godot `(0,-1,+1)`.
- `reload_resources()` resolves the active AO resource pack, clears cosmetic falling batches and smoke texture caches, and refreshes terrain colors/AO while retaining collision shapes. A replacement AO atlas with dimensions other than 256² falls back to the original.
- `get_topdown_image()->Image` returns a full-resolution x/z image with highest-solid RGB and opaque alpha, matching `GLFlatMapRenderer::GenerateBitmap`. It caches one Image and rescans only edited top columns. Buried edits do not require rescanning. Reset/import replaces the Image; consumers can use a shared nearest-filtered ImageTexture and throttle updates after `blocks_changed`. Empty lab columns are transparent.
- `rebuild_now()` flushes pending mesh and collision changes, useful after a reset, import or deterministic test.
- `blocks_changed(changes)` sends entries `{cell, before, after, collapsed}`. It exposes collapse removals to sound/particles, UI diagnostics, replay and future network transport.
- `map_loaded(map_name)` announces a completed reset/import. `get_stats()` reports loaded chunks, visible faces, dirty chunks and packed data memory.
- `falling_cluster_created(cluster)` announces one cosmetic grouped mesh per unsupported connected component. `falling_cluster_finished(position, block_count, reason)` announces native collision/timeout breakup, useful for sound and camera shake; `get_effect_stats()` reports active clusters and allocated fragments/smoke.
- `set_effects_observer(position)` updates observer distance for effects; `set_view_position()` also updates it on both lab and native maps. `get_effects_observer()` provides the current position at impact.
- `water_level=1.0` is the original visible water plane (source geometric z=63), while `wade_origin_level=2.0` maps the original player's GetOrigin z>62 threshold. `set_water_enabled(bool)` toggles the plane and rebuilds dry/water floor drawing. `set_water_fog(color,distance)` aligns water fog with the environment. `set_water_fog_enabled(bool)` controls the shader's own channel-dependent haze, which otherwise ignores Environment fog; the toggle persists through map recreation and resource refresh.
- `set_water_waves_enabled(bool)` and `set_water_refraction_enabled(bool)` toggle actual spectral normals and screen refraction. Disabled waves stop their CPU updates and GPU wave target; `get_water_stats()` reports mode count/texture memory and explicitly identifies the bounded spectrum rather than full native FFT.
- `set_reflection_camera(Camera3D)` binds the player's camera. `set_water_reflections_enabled(bool)` controls a real clipped geometry reflection pass; it defaults off pending exported-browser performance checks. `set_water_reflection_budget(Vector2i, hz, geometry_instances)` configures bounded resolution/update frequency/proxy counts and persists through map resets. `get_reflection_stats()` exposes actual selected geometry/lights, omitted counts, registry limits, requested passes, measured CPU preparation and rendered draw calls. Water-off suspends the pass as well.
- `clip_box(position)` and `clip_world(position)` map native clipping rules for falling models and particles. Horizontal out-of-map coordinates are solid for ClipBox and air for ClipWorld; both clamp the bottom cell to y=1 and treat positions below the map as solid.

## Rendering and collapse

Each 16³ chunk is one `StaticBody3D`, one `MeshInstance3D`, and one `CollisionShape3D`. `ArrayMesh` emits only exposed faces, including cross-chunk culling, with four indexed vertices per face. An 18³ packed halo caches raw blocks and renderer occupancy for culling/AO. Vertex RGB preserves the VXL palette; vertex alpha stores ambient occlusion. The shared lit Compatibility shader receives directional/omni/spot lights and Godot shadows.

AO-dependent chunk invalidation includes diagonal neighbors: a corner edit dirties eight chunks, an edge four, a single border two, and an interior one. Collider invalidation uses only geometry changes and directly touched face-neighbor chunks. Repainting and AO-only neighbor updates retain existing collision objects. Collider faces greedily merge exact coplanar cells into rectangles; render faces remain separate for per-corner AO. A uniform 16×2×16 slab retains 640 rendered voxel faces but has six collision rectangles. Openings and steps retain their exact physical shape.

`_process` stops after three completed chunks or four milliseconds of rebuild work, whichever happens first. One chunk is indivisible and can exceed this time budget; synchronous reset/import/tests flush with `rebuild_now()`. `ConcavePolygonShape3D` is used only for static world geometry.

After removal, neighboring solid components are tested for six-neighbor connectivity to the bottom two layers. Floating components are removed and marked `collapsed`. Downward search is prioritized. This preserves the native support rule; the implementation uses local depth-first searches instead of OpenSpades' maintained link forest. Floating components already present in an imported map remain until affected by a removal, as in the source.

Support traversal stops as soon as a solid bottom-layer neighbor or a component already proven supported is found; it does not traverse the remaining terrain after finding ground.

## Falling presentation (W09)

`falling_cluster.gd` preserves `FallingBlock.cpp`'s cosmetic behavior: one mesh centered at the mean voxel center, gravity 4 m/s², local rotation around mapped source axis `(1,0,1)` with incremental angle `time * 1.4 * dt`, and breakup when elapsed time exceeds one second or its center enters ClipBox geometry. Authoritative blocks remain removed; fallen models never settle as new terrain.

At breakup, only component surface cells emit particles. The normal count is six white fragments and one original animated Smoke1 sprite per surface cell. Two MultiMesh batches replace individual particle nodes. Smoke runs at source 70 fps, grows from radius 1 at 0.5 units/s, has lifetime 1–1.5 seconds and ignores collisions. Fragments have source triangular random velocity scaled by 13, radius 0.35–0.45, gravity 19.2 m/s², lifetime two seconds and a one-second fade. Near impacts (observer distance <16 m and cluster <1000 blocks) use native axis selection and 0.36 velocity damping for weak bounces; other fragment collisions delete the sprite. Impacts farther than 170 m allocate no particles.

Browser budgets are explicit: at most 24 active clusters, 4096 fragments and 1024 smoke sprites per cluster. Larger surface sets are sampled uniformly. For sets below these budgets, counts follow the native six-plus-one rule. Source original rendering also emits camera vibration proportional to `block_count / 100 / (distance + 5)` clamped to one; the world emits the breakup event so presentation can apply it. These caps preserve map rules while adapting effect load.

## Water and renderer baseline (U14)

The lab contains a 16² pool at x/z=72..87, with y=1..3 excavated above immutable y=0. Native maps use the same plane. Submerged y=0 floor faces are hidden visually while static box-controller collision remains available.

`spectral_wave.gd` follows the spectrum/phase/matrix and byte encoding in `GLWaterRenderer.cpp::FFTWaveTank`: inverse-square frequency amplitude with Gaussian suppression, random phase and four random matrix components, source uint32-derived phase speed, upper-16-bit phase quantization, and periodic central-difference normal samples. A 128² GPU target evaluates the 32 strongest non-DC modes. Default one layer uses 64 KiB RGBA8 and native low-water sampling scales .08/.15704/.02344. The helper also supports three independently seeded layers, but current water uses the original low-quality one-bank path. This is a truncated source-shaped inverse spectral sum, not the original complete 128²/256² FFT or the medium/high three-tank renderer. Godot RNG also differs from native RNG.

`water.gdshader` samples the actual opaque screen/depth buffer, reconstructs depth using Compatibility's OpenGL NDC range, guards displaced samples against above-water foreground objects, and uses the native depth envelope `1-(1-clamp(thickness,0,1))²`. Source floor colors, Fresnel fourth power +.03 and per-channel horizontal fog are retained. Floor lighting and specular normals receive Godot Sun/omni/spot lighting; already-rendered refracted/reflected colors use emission to avoid lighting rendered images twice. The optional planar pass below reflects actual geometry; disabled/out-of-target samples retain the sky fallback. Water3 screen-space reflection/refraction depth raymarch, complete native FFT, native water shadow/radiosity lookup, high-water mesh displacement and exact GL GGX composition remain unimplemented. Transparent objects are absent from Godot's opaque refraction screen snapshot.

Native defaults use horizontal fog/culling distance 128 m and release at 160 m; our default streaming radius four chunks implies a 64 m water fog distance. Root owns environment/fog/lighting decisions. Actual GPU probes establish refraction, wave data, animation, lighting and above-water object stability; exported-browser appearance/performance remains an acceptance requirement.

## Bounded planar water reflection

`planar_reflection.gd` follows `GLRenderer.cpp`'s mirrored view around source z=63 and `Water2.fs`'s separate mirror image plus wave distortion. The reflected camera mirrors the eye/up/forward around the actual water plane. Its local X reverses to retain a valid positive-determinant Godot camera basis; the water shader projects world positions into that camera and samples the corresponding physical reflection. Camera offsets are applied once and perspective/orthographic/frustum modes preserve the source aspect/projection settings.

Godot4.7.2's public Camera3D/RenderingServer API has no arbitrary oblique projection setter. A separate explicit World3D therefore contains RenderingServer geometry proxies with fragment clipping below water. Chunk/model mesh and MultiMesh resources are shared; voxel data, mesh vertices and physical collision are not duplicated. Original terrain/custom shaders are copied with an injected view-to-world clipping test and current uniforms, preserving AO/GI/light response. Original static KV6 StandardMaterial meshes use a bounded adapter for vertex colors, tint, albedo texture, emission, roughness/metallic/specular, simple transparency and billboarding. Sprite textures/tints and current source transforms are synchronized. Geometry resource replacement rebinds clipping materials; node removal releases proxies. An event-maintained geometry/light registry avoids rescanning the whole scene on every pass. Resource reload clears cosmetic reflection material/proxy caches.

Render layer20 (`1<<19`) belongs to water; layer19 (`1<<18`) belongs to first-person arms/equipment and the screen-depth post quad. The reflection excludes both. Canvas postprocessing/HUD never enters its scenario. Main Camera's ordinary all-layer mask still sees these elements. Fully submerged geometry is culled before allocation, and partially submerged geometry is clipped per fragment. Live source directional/omni/spot lights and environment are copied; additional reflection shadow atlases are disabled. The main view retains its own shadows.

Default work limits are320×240 maximum (320×180 at16:9),20 requested passes/second,768 geometry proxies,16 lights and4,096 registry traversal/registered-node entries. Targets clamp to32..512 per axis, frequency1..30Hz and geometry8..1,024. Candidates select nearest visible source geometry within draw distance plus their bounding extent; counts omitted by the geometry/registry cap are reported. An RGBA8 target plus nominal32-bit depth at320×240 costs about614,400 bytes before driver overhead; geometry/material/RID metadata is additional. RenderingServer instances are per existing mesh/chunk/batch, never per cube. Static transforms/material bindings avoid repeated server writes. A submerged eye or a camera aimed sufficiently upward suspends the surface-only pass; native water occlusion-query skipping is not implemented.

This is an explicit Compatibility adaptation, not the complete native mirrored renderer: no additional reflected shadows, Water3 mirror-depth raymarch, native roughness mip chain, arbitrary extension PBR normal/parallax/ORM maps, skeleton skinning or general extension custom-shader include-only fragments are claimed. Source fragment/smoke MultiMeshes retain their current main-view billboard transforms; Sprite proxies face the mirror camera. Registry or geometry/light caps can omit content in busy scenes. Texture updates can be visibly delayed at the bounded rate. Reflection defaults off until measured in the actual exported browser.

## Terrain lighting and AO (U14)

`voxel_ao.gd` follows `GLMapChunk::calcAOID`: for each exposed face, evaluate the eight axial/diagonal neighbors around its exterior air cell, using the native mapped tangent orientation. The resulting 8-bit ID selects a 16² tile in the original 256² `Gfx/AmbientOcclusion.png`. UV2 stores `(tile origin + native corner pixel + .5)/256`, matching `BasicBlock.vs`; the shader samples the full rounded tile detail per fragment with linear, non-mipmapped filtering. Four red-channel corner values remain cached in mesh alpha for CPU checks and the explicit corner quality fallback. Native horizontal map edges wrap for AO, below-map samples are solid, above-map samples air, and water bottom sampling uses layer y=1. Physical collision remains bounded.

The native empty tile is 1.0; negative-u occlusion has corner 184/255; dense tile255 has corner112/255. Actual GPU comparison demonstrates that full atlas interior detail differs from interpolated corner shading. AO is a data texture without source-color conversion, and half-pixel tile bounds avoid sampling adjacent tiles.

`terrain.gdshader` uses Lambert diffuse lighting, full roughness, no direct specular, and ambient-only AO (`AO_LIGHT_AFFECT=0`). Palette RGB is unchanged on all orientations. Dynamic point lights and flashlight spots remain effective inside AO-darkened corners. Native OpenSpades uses fixed sun coefficients plus ambient/radiosity volumes; Godot normal-based lighting, shadow maps and environment fog are explicit renderer adaptations. Native per-voxel radiosity volumes, ambient-shadow volumes, SSAO and exact per-channel terrain fog are not implemented.

Actual Compatibility GPU checks on Intel UHD/OpenGL3.3 verify omni light, spot light, ambient-only AO, caster→receiver shadow and a rendered palette pixel. The backend's additive shadow path changes gamma/brightness relative to its shadows-off path and showed self-shadow bands, also with stock StandardMaterial3D. Comparing whole-scene means across those two paths is therefore misleading; the shadow test holds the shadow path active and toggles only mesh casting, including a known floor point under the pillar shadow. Browser appearance/performance remains an acceptance requirement; these checks do not claim native GL visual parity.

## Bounded source palette irradiance

`voxel_irradiance.gd` implements `GLMapShadowRenderer::GeneratePixel` and `GLRadiosityRenderer::Evaluate`: the first Sun-visible voxel face is cached in the source projected `(x,y-z)` shadow column, with 6-bit palette channels and top/side face metadata. A 13² envelope sums face cosine, `1/(distance+.4)²` falloff and source normalization `.1/64`, producing base and three directional RGB coefficients. The shader combines these with the actual surface normal and the source factor1.5. This transfers surface colors to adjacent geometry; it is neither a constant ambient slider nor recursive multi-bounce transport.

For browsers, four signed RGB16F textures sample a 4 m observer-centered lattice, capped at33×17×33:18,513 probes,444,312 GPU coefficient bytes and888,624 CPU packed coefficient bytes. CPU image copies and the lazily populated shadow dictionary add memory; shadow entries cap at65,536. Native GL stores four full512×512×64 volumes instead. Coarse trilinear samples can leak light through thin walls and blur small features. Volume bounds return zero, and no separate long-range ambient-shadow volume or SSAO is included.

Dirty block/color edits invalidate source shadow columns and nearby probes. Initial warming prioritizes observer columns/height. Movement recenters on16 m boundaries and reuses completed overlapping probes; fresh border probes warm incrementally. A frame targets2 ms and at most24 probes, then uploads at most once per six update frames or when warming completes. One source probe/whole texture upload is indivisible and can exceed2 ms; reported last/max update times expose this. Initial native-volume warming can take tens of seconds at this budget. GI defaults off until browser costs are measured.

Tests compare independently calculated native white-plane coefficients, black at sky-depth zero, palette repaint/removal invalidation, memory/count caps, observer overlap reuse and actual GPU red/green transfer onto unchanged white geometry. In the local Compatibility renderer, raw shader radiance and eight-bit framebuffer values differ; rendering the CPU query through a constant reference material produces exactly the same pixel as RGB16F GI. The numeric GPU test compares these through the same renderer color transfer rather than assuming framebuffer RGB is linear.

## VXL saving

The encoder follows `GameMap::Save`: identify six-neighbor surfaces, emit upper surface colors, implicit solid interior, lower surface colors and the following air interval. Native x/z map edges are not air neighbors for save-time surface selection, matching the source. Colors are B/G/R bytes and native health 100. Every column must end in a solid immutable floor. Valid zero-upper-color spans (`top_end = top_start - 1`) occur when a lateral surface patch splits otherwise-solid interior; these are supported by both encoding and decoding.

VXL stores exposed surface colors rather than every underground voxel color. Repainted surfaces and newly exposed recolored interior cells survive saving; colors wholly buried in solid interior revert to the decoder's default earth color. This is a format limitation shared with the native encoder.
